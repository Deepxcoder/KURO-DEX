# KURO-DEX | Workout Web Player & Biometric HUD

Production-ready Next.js 15 workout web application and live markdown editor for `Workout.md`.

## Features
- **Volume Analytics Matrix**: Interactive SVG volume curve with 7D, 30D, 3M, 1Y timeline scaling.
- **Biometric Kinetic Skeleton**: Interactive 2D body map highlighting muscle groups (Pecs, Lats, Quads, Hamstrings, Deltoids, Biceps, Triceps, Abs, Calves) with kinetic glow and fatigue index.
- **Live Obsidian Vault Sync**: Synchronizes seamlessly with `Workout.md` via direct filesystem reading and GitHub REST API commits.
- **Theme Switcher**: 1-click toggle between Cyberpunk Neon Dark HUD and Ultra-Clean Light Mode.

## Development
```bash
npm run dev
# or from root:
npm run player
```

## Production
```bash
npm run build
npm run start
```
